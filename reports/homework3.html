If the final_score is not centered, then this implies that something else is having an effect on the response and that the errors are not random. The RMSE reveals the typical amount fitted values are from the true value, which the means of the residuals itself does not because values above cancel out values below the fit. This is because the latter, X * beta_hat, performs element-wise multiplication and not the cross-product, which is what is needed for least squares regression.

Part 4 Summary

It is True that Q @ R is approximately X. This is important because it verifies that X can be represented as matrices Q and R. It is also True that Q.T @ Q is approximately \(I\), which verifies that Q has orthonormal columns.

The singular values tell us the strength about the direction of the data. Larger singular values indicate a larger direction, indicating the corresponding \(\mathbf{v_i}\) holds a large amount of information of the original X. The largest singular value of the standardized X is \(\sigma_1 =\) 12.1281. The weakest is \(\sigma_4 =\) 7.2924. The condition number represents the ratio between \(\sigma_1\) and \(min(\sigma_i)\), which reveals how much stronger \(\sigma_1\) is in comparison to \(min(\sigma_i)\). If this number is large it suggests that some predictors hold a much smaller amount of information of the data in comparison to others, and possibly suggests multicollinearity or redundancy.

The condition number before standardization (1513.065) is much larger than the standardized condition number (1.6631) because of the scale of units. Some measurements naturally produce much larger numbers than others, which can cause a smaller measurement to look insignificant compared to a larger one making it harder to determine redundancy in the data.

In the case of the student performance data, the rank of the standardized X (4) equals the number of columns (4) and the condition number (1.6631) is small indicating that there is no evidence of severe near-redundancy among predictors.

Part 5 — Reproducibility and numerical-computing reflection

Clean execution matters for a computational report because you cannot hand somebody broken or messy code and expect the other person to understand what the script does or how to fix it; the code should execute without complication and read almost like a book. The code should not depend on a hidden notebook state because the notebook cells should be executed in order. A cell that executes properly should not rely on another cell that comes after to be execute first. This creates confusion and requires the user to read carefully and not run things out of order. Similarly, the code should execute flawlessly after restarting the kernel to ensure that results are not influenced by cached variables that should not exist.

When fitting a linear model, np.linalg.lstsq() is preferable to \((X^TX)^{-1}X^Ty\) as it is less error prone, requires only a single line, and finds the fit by using SVD. The use of SVD means that X is never squared or inverted, resulting in higher precision because a computer can only store so many floating point values. Squaring a large/long number can result in the computation becoming numerically unstable. Additionally, the problem of floating point precision can mean that checks for exact equality for QR and SVD reconstruction may return false, which is why np.allclose() is preferable.

The condition number is an important diagnostic step as it can reveal redundancy but only if the data is on the same scale. If the data is not on the same scale then large numbers dominate and explode the condition number making it harder to distinguish if there is redundancy among predictors. If the data is standardized then a high condition number is an indicator of redundant predictors.
